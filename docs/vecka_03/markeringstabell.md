## Markeringstabell: zonförslaget prövat mot checklistan

| Plats i zonförslaget | Kontrollfråga som faller | Var den implicita tilliten ligger | Föreslagen ändring | Vad ändringen kostar i drift |
|---|---|---|---|---|
| Loggzon (10.40.50.0/29), loggflöden från DMZ, Serverzon, Databaszon och jump på TCP 514 | 2. Måste en server visa vem den är, oavsett var i nätet den sitter? | Loggar skickas okrypterat, och loggservern litar på avsändaren bara för att den sitter i en tillåten zon | Byt till TCP 6514 med TLS, och verifiera avsändaren med certifikat | Certifikat måste skapas, distribueras och förnyas |
| Inom varje zon, till exempel Serverzon (10.40.20.0/27) | 2. Måste en server visa vem den är, oavsett var i nätet den sitter? | Default deny gäller mellan zoner men inte inom dem. Servrar i samma zon når varandra fritt | Mikrosegmentering med värdbrandvägg (nftables) på varje server, så att bara definierade flöden tillåts | Regler på varje server, och mer arbete vid felsökning |
| Adminzon (jump), SSH 22 till alla interna zoner | 3. Når servern bara det den behöver? | Allt som kommer från jump litas på, och ett administratörskonto når alla servrar i sju zoner | Accepterad risk: administratörer behöver nå alla servrar för att kunna administrera dem. Risken kompenseras med separata loggar som admin inte kan ändra | Ingen extra kostnad, men om ett administratörskonto tas över når angriparen allt |
| Klientzon → Serverzon, "Nödvändiga tjänster" | 3. Når servern bara det den behöver? | Hela klientzonen får nå hela serverzonen, utan angivna portar | Skriv ut exakt vilka tjänster och portar klienterna behöver, och neka resten | Måste uppdateras varje gång en ny tjänst läggs till |
| Behörig administratör (extern) → Adminzon, SSH 22 | 4. Krävs mer än rätt nät för att få åtkomst? | Skissen säger inte vad som gör en administratör "behörig". Om bara en SSH-nyckel krävs räcker en stulen nyckel | Kräv nyckel plus MFA, och begränsa vilka källadresser som får ansluta | MFA måste sättas upp, och administratörer som jobbar hemifrån behöver en fast adress eller VPN |
| Alla servrar, säkerhetsläge | 5. Påverkar en servers säkerhetsläge om den får åtkomst? | Servrar får åtkomst oavsett patchnivå | Övervaka patchnivå och flagga servrar som saknar viktiga uppdateringar | Kräver ett verktyg och någon som följer upp |
| Adminzon (jump) → Loggzon, SSH 22 | 7. Kan vi i efterhand se vem som har loggat in, när och varifrån? | Den som tar över jump kan också logga in på loggservern och radera spåren | Separat konto för loggadministration, och loggar som bara kan läggas till men inte ändras eller raderas | Ett extra konto att hantera, och loggarna tar mer plats |
