# Baslinje-luckor – elev-46

Tre saker teamets trafikbaslinje från vecka 1 inte säger något om:

1. Tider på dygnet som baslinjen inte täcker – den bygger på en kort fångst.
2. Paket som aldrig passerade fångstpunkten – det som inte fångades syns inte.
3. Innehållet i krypterade sessioner – baslinjen visar mål och mängd, inte vad som skickas.
